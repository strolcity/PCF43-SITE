📊 Méthodologie des calculs

Les voix affichées sont des voix ventilées : pour chaque nuance officielle, les voix sont redistribuées entre les partis (PCF, LFI, PS, EELV...) selon un poids calculé à partir du nombre d'élus à l'Assemblée Nationale.

  • FG 2012 → 46,7 % PCF + 53,3 % LFI — élus GDR 2007 (15 PCF, 15 DVG filiation LFI)
  • FG 2017 PRES → 48,5 % PCF + 51,5 % LFI — élus GDR 2012 (16 PCF, 17 LFI)
  • NG 2017 PRES → 90,3 % PS + 9,7 % EELV — élus groupe Nouvelle Gauche AN 2017
  • NUP 2022 LEG → PCF 11,9 %, LFI 40,8 %, PS 34,8 %, EELV 12,5 % — élus AN 2024
  • UG 2024 LEG → PCF 8,8 %, LFI 37,3 %, PS 34,2 %, EELV 19,7 % — élus AN 2024
  • SOC, RDG, DVG → PS à 100 % par convention
  • ECO, VEC → EELV à 100 %

Pour la Haute-Loire en législatives, les voix des circonscriptions 4301 et 4302 sont additionnées.

La courbe d'abstention = (Inscrits − Votants) / Inscrits × 100.

Les gains/pertes comparent chaque élection à la précédente dans l'ordre chronologique sélectionné.

Sources : Ministère de l'Intérieur. Calculs PCF 43.
